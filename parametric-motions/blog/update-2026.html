Update - August 2026: the curves are back, and this time you can play with them

Seven years after I first wrote this post, I dusted off these four parametric equations and rebuilt the whole experiment as a single canvas app called Parametric Motions. The original msapp link died along with the old PowerApps Community Apps Gallery, so this update fixes that in a more permanent way: the full source code now lives on GitHub, and you can build and deploy the app into your own environment with the Power Platform CLI.

The new app puts all four curves behind a hamburger menu, and each one gets its own screen: a small circle traces the curve across a dark plotting canvas, leaving a colored trail behind it, while sliders let you change the equation parameters live - change a frequency or petal count and the trace restarts with the new shape. It is dangerously easy to lose half an hour just dragging sliders on the Hypotrochoid screen.

Lissajous Curvex = A·sin(a·t + δ)    y = B·sin(b·t)
Rose Curver = A·cos(k·θ)
Spiral (Archimedean)r = a·θ
Hypotrochoidx = (R−r)·cos t + d·cos(((R−r)/r)·t)    y = (R−r)·sin t − d·sin(((R−r)/r)·t)

Under the hood the technique is a modernized take on what I showed in the video back in 2019: a repeating Timer control still drives the motion, but instead of just moving a circle around, each tick advances a step counter and the trail is rendered as an inline SVG polyline - a Concat(Sequence(...)) formula evaluates the parametric equations at 600 points along the curve and feeds the result to an Image control as a data:image/svg+xml URI. Everything derives from that one counter plus the slider values, so pause, resume, and restart are each a one-line formula.

Also new since 2019: canvas apps now have a proper YAML source format (*.pa.yaml), which means the app is authored and versioned as readable source code rather than a binary msapp. The GitHub repo contains the YAML source, a Dataverse solution wrapper, and a build.ps1 that packs and imports the whole thing with pac - clone it, point the CLI at your environment, and you are drawing curves in minutes:

The math has not changed since 1815; the tooling certainly has.
